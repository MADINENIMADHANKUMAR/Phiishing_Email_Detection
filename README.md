# Phishing Email Detection Model
A Machine Learning based phishing email detection system built using Python and Scikit-learn.  
This project classifies emails as **Phishing** or **Safe** using textual analysis, suspicious keyword detection, and URL-based features.
---
# Features
- Train model on phishing and legitimate emails
- Detect suspicious URLs in email content
- Analyze phishing-related keywords
- Use TF-IDF vectorization for text processing
- Predict whether an email is:
  - Phishing
  - Safe
- Display:
  - Accuracy Score
  - Classification Report
  - Confusion Matrix
- Test custom email messages interactively
---
# Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- TF-IDF Vectorization
- Logistic Regression
